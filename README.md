## What is Exchange Rate?

Exchange Rate is a small browser-based app built around USD rate comparisons. You can look up how currencies stack against the dollar without installing desktop software or relying on a terminal workflow.

It fits people who want a fast lookup—casual users, students, or developers inspecting a compact HTML utility. Because the scope stays narrow, the UI and flow stay aimed at currency data rather than extra tooling.
